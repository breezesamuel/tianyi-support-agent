9. 操作审计日志（会话创建/分配、配置、知识库、坐席变更）

### 7.3 仍存在的差距（诚实说明）

- **语音渠道**：竞品普遍具备 Voice AI（Fin Voice 2、Decagon Voice 3、Sierra 59 语言语音），本应用无语音能力，需服务端与电话网关。
- **全渠道**：竞品覆盖 WhatsApp/Slack/邮件/短信/小程序，本应用仅 Web。
- **多语言深度**：本应用为界面级中英双语，未接入实时翻译与多语言知识库检索；长尾语言、会话中切换语言暂不支持。
- **服务端闭环**：CRM/支付/订单真实查询、SSO、细粒度权限、全量 QA 评分与 WFM 需后端与外部账号，纯静态实现无法覆盖。
- **云端同步**：当前为 Supabase 单 JSON 记录方案（可选启用），非生产级多租户数据库；未配置时数据仍在本地浏览器。
